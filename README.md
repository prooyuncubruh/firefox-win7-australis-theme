## How to Install

1. Open Firefox and go to `about:config`.
2. Search for `toolkit.legacyUserProfileCustomizations.stylesheets` and set it to **true**.
3. Download `chrome.zip` from this repository and extract it.
4. Go to `about:profiles` in your address bar, find your active profile, and click **Open Folder** next to *Root Directory*.
5. Copy the extracted `chrome` folder into your profile folder.
6. Restart Firefox.
