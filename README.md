## How to Install

1. Open Firefox and go to `about:config`.
2. Search for `toolkit.legacyUserProfileCustomizations.stylesheets` and set it to **true**.
3. Go to `about:profiles` in your address bar, find your active profile, and click **Open Folder** next to *Root Directory*.
4. Copy the `chrome` folder from this repository into your profile folder.
5. Restart Firefox.
